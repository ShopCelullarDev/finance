## Fase 1: Recopilación y Arquitectura

### 1. Clasificación de Fuentes de Datos (45+ Fuentes)
* **Vector 1 (Tiempo Real - WSS/APIs):** Binance (Global/US), Kraken, Coinbase, CoinMarketCap, Polymarket Gamma API.
* **Vector 2 (Flujo Institucional - Smart Money):** CapitolTrades, QuiverQuant, Dataroma, WhaleWisdom, OpenInsider, InsiderArbitrage.
* **Vector 3 (Noticias y Sentimiento NLP):** FinancialJuice, Jin10, ZeroHedge, Reuters, Bloomberg, FT, WSJ, Nikkei, Investing, Yahoo, SeekingAlpha.
* **Vector 4 (Macro, Energía y Commodities):** EIA.gov, IEA, CME Group, TradingEconomics, OilPrice, Kitco, LBMA, FreightWaves, Vortexa.

### 2. Esquema de Base de Datos (TimescaleDB)
```sql
CREATE EXTENSION IF NOT EXISTS timescaledb;

CREATE TABLE assets (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    asset_type VARCHAR(30) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE market_ticks (
    time TIMESTAMPTZ NOT NULL,
    asset_id INT REFERENCES assets(id),
    source VARCHAR(50) NOT NULL,
    price NUMERIC(18, 8) NOT NULL,
    volume_24h NUMERIC(24, 8),
    bid_ask_spread NUMERIC(10, 6)
);
SELECT create_hypertable('market_ticks', 'time');

CREATE TABLE news_events (
    id BIGSERIAL,
    published_at TIMESTAMPTZ NOT NULL,
    source VARCHAR(100) NOT NULL,
    title TEXT NOT NULL,
    url TEXT UNIQUE,
    sentiment_score NUMERIC(4, 3),
    affected_assets VARCHAR(20)[],
    PRIMARY KEY (id, published_at)
);
SELECT create_hypertable('news_events', 'published_at');

CREATE TABLE predictive_signals (
    id BIGSERIAL,
    generated_at TIMESTAMPTZ NOT NULL,
    asset_id INT REFERENCES assets(id),
    timeframe VARCHAR(10) NOT NULL,
    action_suggested VARCHAR(20) NOT NULL,
    confidence_score NUMERIC(5, 2) NOT NULL,
    entry_price NUMERIC(18, 8),
    stop_loss NUMERIC(18, 8),
    take_profit NUMERIC(18, 8),
    trigger_factors JSONB NOT NULL,
    PRIMARY KEY (id, generated_at)
);
SELECT create_hypertable('predictive_signals', 'generated_at');
